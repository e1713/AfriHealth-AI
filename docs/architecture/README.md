# Architecture Documentation

## Purpose

This folder is the planned home for approved system architecture, product-module architecture, interoperability profiles, and data-flow documentation.

## Scope

Documents here describe the approved production architecture and its requirements. Production uses Intron API / Intron Sahara v2.5 for speech workflows, current production language scope is Amharic-English code-switching, and deployment is frozen at Cloudflare Pages → Railway Backend → Intron API.

This folder does not authorize implementation, deployment changes, code refactoring, or future-language support. Existing root documents have not been moved.

## Future use

After separate approval, architecture documents may be organized here with links and compatibility paths reviewed. Keep historical discovery reports clearly identified as historical evidence.
