# Policies and Standards

This directory is intended for approved organizational policies and standards
that govern AfriHealth AI, including privacy, security, records management,
access control, and operational controls.

No approved policy or standard is established by this index. Document owners,
approving authorities, and effective dates are **UNKNOWN** unless explicitly
recorded in an approved document.

Do not store patient records, recordings, transcripts, credentials, or
restricted evidence in this directory. See the
[governance registry and intake framework](../governance/AFH-GOV-REG-001-documentation-governance-registry.md)
for the proposed documentation lifecycle.
