# Governance Evidence

This directory is for governance evidence maintained in the repository. Use
the subdirectories for their named evidence categories:

- [Approvals](approvals/README.md)
- [Meeting notes](meeting-notes/README.md)
- [Clinical reviews](clinical-reviews/README.md)
- [Security decisions](security-decisions/README.md)
- [Change logs](change-logs/README.md)

Do not add fictional, patient-identifying, confidential, or otherwise
restricted evidence here. No evidence is created by this directory structure.
