# Benchmark Governance Documentation

This directory is intended for approved benchmark governance, evaluation
protocols, data provenance, consent and de-identification controls, and
limitations on benchmark-derived claims.

Historical benchmark materials remain under `archive/benchmark/` and are not
moved or promoted by this index. Their presence does not establish approval
for reuse or publication. Current benchmark governance ownership and approval
status are **UNKNOWN**.

Do not store restricted recordings, patient records, credentials, or
unapproved evaluation data in this documentation directory. See the
[governance registry and intake framework](../governance/AFH-GOV-REG-001-documentation-governance-registry.md)
for the proposed documentation lifecycle.
