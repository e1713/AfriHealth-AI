# Roadmaps and Phase Plans

## Purpose

This folder is the planned home for phase plans, execution roadmaps, technical-debt priorities, and completion reports.

## Scope

Roadmaps communicate scope, dependencies, blockers, risks, and approval gates. A plan does not authorize code, deployment, cleanup, archive, or dataset actions unless explicitly approved.

Existing Phase 0 and Phase 1 planning documents remain in their current locations.

## Future use

After separate approval, planning documents may be grouped by phase with dates, status, and supersession relationships retained. Do not rewrite historical reports to imply later work occurred.
