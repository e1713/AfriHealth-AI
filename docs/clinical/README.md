# Clinical Governance Documentation

This directory is intended for clinically governed workflow descriptions,
clinical safety requirements, review responsibilities, escalation protocols,
and clinical validation records.

This scope page does not establish a clinically approved protocol or authorize
clinical use. Clinical owners, approving authorities, and approval status are
**UNKNOWN** unless recorded by the accountable organization.

Do not store patient records, recordings, transcripts, or identifiable
clinical examples here. See the
[governance registry and intake framework](../governance/AFH-GOV-REG-001-documentation-governance-registry.md)
for the proposed documentation lifecycle.
