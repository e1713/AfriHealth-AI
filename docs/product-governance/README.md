# Product Governance Documentation

This directory is intended for controlled product-governance records,
including intended use, product risk management, requirements traceability,
release decisions, change control, and lifecycle oversight.

This index does not assert that these controls or approval processes are
implemented. Product-governance owner, approving authority, and current
approval status are **UNKNOWN** unless recorded in an approved document.

Do not store patient records, recordings, transcripts, credentials, or
restricted evidence here. See the
[governance registry and intake framework](../governance/AFH-GOV-REG-001-documentation-governance-registry.md)
for the proposed documentation lifecycle.
